# AstroTrack

AstroTrack is a dedicated software for proactively monitoring astronaut health in space, in a base, or in a haze. It doesn't matter the conditions--if they can read, they can lead.

## Run
    pip install fastapi uvicorn
    uvicorn api:app --reload

## Where was AI (Artifical Intelligence) used?

AI was used in portions of the frontend development. All other sectors like architectural, design, condition engine, and backend, was all developed by me.

## NASA Resources Used
`https://www.nasa.gov/hrp/hazard-hostile-closed-environments/` was used for setting realistic expectations for **astronaut** health in space instead of on earth.

`https://www.nasa.gov/reference/3-0-health-and-medical-care/` was used for medical procedures (3.4-7) and suggestions given by AstroTrack.
